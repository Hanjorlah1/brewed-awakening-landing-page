# Brewed Awakening

A modern, elegant, and fully responsive landing page for a fictional specialty coffee shop located in Victoria Island, Lagos. Built to showcase clean user interface design, dynamic user interactivity, and fluid responsive layouts.

## 🔗 Live Demo

Explore the live project here: [Brewed Awakening Live Demo](https://hanjorlah1.github.io/brewed-awakening-landing-page/)

## 🚀 Features

- **Fully Responsive Design:** Optimized seamless transitions across mobile, tablet, and desktop viewing displays.
- **Sticky Navigation:** Persistent header configuration featuring an integrated mobile hamburger drawer menu.
- **Interactive Modals:** A fully functioning "Book a Table" reservation overlay module.
- **Dynamic Content Modules:** Custom-styled menus displaying real-time currency options, descriptions, and a responsive multi-image layout carousel showcasing the physical workspace.
- **Faceted Search Interface:** A built-in client-side localized site search system with dynamic empty-state feedback alerts.
- **Fluid Layout Architecture:** Smooth hardware-accelerated scrolling mechanisms paired with clean transitions.

## 🛠️ Technologies Used

- **Markup & Layout:** HTML5, Semantic Elements
- **Styling & Presentation:** CSS3, Flexbox, CSS Grid, Google Fonts API
- **Framework UI Components:** Bootstrap 5 (Carousel, Modals, Responsive Breakpoints)
- **Client Scripting:** JavaScript (Vanilla ES6+)

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Hanjorlah1/brewed-awakening-landing-page.git
   ```

2. **Navigate into the project folder:**
   ```bash
   cd brewed-awakening-landing-page
   ```

3. **Launch the project:**
   Simply open the `index.html` file directly inside your preferred web browser, or use a local development server extension like *Live Server* in VS Code.
